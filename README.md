# gadgetroast

[![make.fun](https://make.fun/badge/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610.svg)](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)

A one-line roast of the gadget you use every day: the humble printer, a machine that demands ink, paper, Wi-Fi, a driver update, and a pep talk before it will condescend to print a single page. The joke works because it is specific — every item on the list is a real, familiar printer failure — and because the payoff shrinks the whole ordeal down to one page, making the printer sound less like office equipment and more like a dramatic coworker who needs encouragement to do the bare minimum.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the entry to `./out/entry.txt`.
